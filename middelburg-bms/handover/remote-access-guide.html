Middelburg BMS Dashboard:
Remote Access Setup Guide

Secure access to the live monitoring dashboard from any location.

This guide explains how to access the live Middelburg BMS monitoring dashboard from any remote location using a secure, private network.

1

Accept the Tailscale invitation

  1. Check your email inbox for an invitation from Tailscale to join the network.
  2. Click the unique invite link inside that email.
  3. Sign in to accept the invite. You can securely use your existing Google, Microsoft or Apple account.
Note: do not use the primary admin email; log in using your own credentials.
2

Install Tailscale on your device

  1. Download the official app for your device from https://tailscale.com
  2. Install the application on the device you plan to use for monitoring (laptop, tablet or phone).
  3. Open the Tailscale app and select Log In.
  4. Authenticate using the exact same account you used to accept the email invitation in Step 1.
3

Verify your connection

  1. Make sure the Tailscale app is running and shows a Connected or Active status.
  2. To test the connection, open a terminal window (PowerShell on Windows, or Terminal on Mac) and ping the host PC:
    ping 100.103.134.56
  3. If you get replies, your secure, encrypted network tunnel to the warehouse is working.
4

Access the live BMS dashboard

Once Tailscale is connected, you can view the live telemetry (room temperatures, fan speeds and JACE status) in your web browser.

  1. Open any modern web browser (Chrome, Edge, Firefox or Safari).
  2. Type this address exactly into the address bar and press Enter:
    http://100.103.134.56:8080

⚠ Troubleshooting tips

  • Page cannot be reached: check the Tailscale app. If it is disconnected or turned off, the dashboard address will not load.
  • No software required: you do not need Python, Node.js or any project code on your computer. The warehouse host PC does the data processing; you only need a web browser and Tailscale.
